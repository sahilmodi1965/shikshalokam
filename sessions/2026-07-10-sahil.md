# Report engine v2 — the STEAM report gets its own identity

## What got made
- **Report engine v2.0.** Split `tools/report/theme.css` into `base.css` (structure, no colour)
  + `themes/<programme>.css` (palette, typefaces, motifs). Reports now link base + their own theme.
- **`themes/steam.css`** — palette *derived*, not chosen: Earth Maroon (the hue ShikshaLokam and
  SCERT Haryana share) + ThinkTac indigo and cyan sampled from the supplied logo files + SL Violet.
- **Brand motifs** (spiral, soil wave, braid) generated as SVG from Guidelines p.15–16.
- **`check_report.py`** — 7 rules that fail the build on known mistakes.
- **`autofit.py`** — solves page fill numerically instead of by eye.
- **STEAM Manch v2 PDF** — 23pp, covers rebuilt, all four partner logos, 10 collages, PASS on all rules.

## What we learned
- Aquib's feedback was one criticism five ways: v1 was NLNF 3.0 with STEAM content poured in.
  The root cause was architectural — `theme.css` welded palette to layout, so a new report could
  not inherit structure without inheriting identity. Restyling would have fixed the symptom.
- **The brand guidelines had been sitting unread.** We had been *inferring* the brand from the NLNF
  report. That inference is what produced the sameness. Guidelines now live in `assets/brand/`.
- **The NLNF 3.0 benchmark itself violates the brand guidelines** — it pairs maroon with green,
  which p.9 forbids outright. "Match the benchmark" was the wrong instruction all along.
  → worth raising with Aquib and Sonal.
- "Several pages are half empty" was **nine** pages, not one. Nobody was measuring. Now R2 measures,
  and R7 catches the opposite failure (overflow), which from the top looks identical to a full page.
- Three engineering traps, each silent: `url()` in a CSS custom property resolves against the HTML
  not the CSS; `fill="var(--x)"` doesn't work as an SVG presentation attribute; percentage
  background-position slides a motif out of view on large elements. All three now have rules.

## What to improve next
- Programme photographs still outstanding — v2 ships on motif placeholders, by Aquib's agreement.
- ASC 3.0 report content received but not yet built — first real test of theme-per-programme.
- Feedback loop is now `LEARNINGS.md` + `check_report.py`. Every future correction should land as a
  rule, not a note. Fix the layer, not the report.
